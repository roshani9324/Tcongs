# TCONGS Infotech – Home Page Redesign

A modern and responsive redesign of the TCONGS Infotech website's Home Page, created as part of the frontend redesign assignment.

## Live Demo

[View Live Website]https://tcongs-nine.vercel.app/

## About the Project

This project focuses on redesigning only the Home Page of the existing TCONGS Infotech website.

The goal was to improve the overall UI/UX while maintaining the existing company content and brand identity.

The redesign focuses on:

- Modern and clean visual design
- Responsive layout for desktop, tablet and mobile
- Improved typography and spacing
- Smooth animations and transitions
- Interactive cards and hover effects
- Dark and premium visual style
- Better content hierarchy
- User-friendly navigation

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript
- Vite

## Key Features

### Responsive Design
The website is designed to work across different screen sizes including desktop, tablet and mobile.

### Modern UI/UX
The existing content has been presented using a cleaner layout, improved spacing, typography and visual hierarchy.

### Animations
Framer Motion is used for subtle entrance animations, hover interactions and smooth UI transitions.

### Interactive Elements
Cards, buttons and other interactive elements include smooth hover and motion effects to improve user experience.

### Custom Cursor
A custom cursor interaction has been added to enhance the overall experience on desktop devices.
